# 投てき前 (X, Z) 落下地点 (X, Z) 飛行方向
投てき方向マップ

矢印＝投てき方向 / 点線＝延長線 / ★＝推定ポータル座標 / 数字＝投てき開始点

使い方：
1. F3キーを押してデバッグ表示を開く
2. エンダーアイを投げる直前の自分のXZ座標を記録する
3. アイが飛んでいき落ちた先のXZ座標を確認・記録する
4. 上の表に入力して「座標を計算」を押す
5. 異なる場所・方向から複数回投げるほど精度が上がります

計算方法： 各投てきの「投てき前→落下地点」を延長した直線を引き、複数の直線が最も近づく点（重み付き最小二乗法）をポータル座標として推定します。後に投げたデータほど重みが大きく、精度に強く影響します。

投てきの角度差が小さすぎて最小二乗法の結果が飛行方向と矛盾する場合は、前方制約付きのレイ交点平均法に自動で切り替えて再推定します。それでも解決しない場合は、平均飛行方向のみを提示しエラー表示します。
