# END PORTAL FINDER

マインクラフト（Java Edition）で、エンダーアイの飛んだ方向からエンドポータルの座標を計算するツールです。
ブラウザだけで動きます（インストール不要）。

## 使い方

1. F3 キーで座標を表示する
2. エンダーアイを投げる直前の自分の X・Z 座標を記録する
3. アイが落ちた地点の X・Z 座標を記録する
4. 表に入力して「座標を計算」を押す
5. 場所と方向を変えて 2〜3 回以上投げると精度が上がります

- 小数点・マイナス値に対応
- 後から入力したデータほど重視して計算
- 投てき方向マップで各投てきとポータル推定位置を確認可能
- スマホ表示に対応（入力欄をカード形式で表示）

## 計算方法

各投てきの「投てき前 → 落下地点」を延長した直線を引き、重み付き最小二乗法で直線が最も近づく点を求めます。
結果が飛行方向と矛盾する場合は、前方制約付きのレイ交点平均法に自動で切り替えます。
詳細は docs/algorithm_report.html を参照してください。
